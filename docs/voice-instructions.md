# 配音语音指令

使用文档中的 `[#指令]合成文本` 格式。`[#…]` 内填写语言、情绪、方言、语气、语速或音调要求，方括号外填写实际朗读的台词。

```text
[#用中文、试探性地说，带一点犹豫、害羞和温柔期待]哎，能……能一起撑伞不？
```

引用上文同样放在 `[#…]` 内，只引用、不合成。例如：

```text
[#用中文，带着久别重逢的激动，轻声说][#是…是你吗？怎么看着…好像没怎么变啊？]你头发长了…以前总说留不长，十年了…你还好吗？
```

- 生成区只有一个提示词输入框，不再提供语气标签或根据标点推测语气的按钮。
- 翻译返回的语气建议直接写入同一提示词，供用户核对后手动生成配音。
- 最终请求的语言、参考音色和时长要求均放入指令块；自动引用的前文也放入指令块，不增加会被朗读的标题或角色名称。
- 已保存的“【配音要求】/【角色语气】/【配音台词】”格式及“用某种语气说：「台词」”在编辑和合成时兼容转换，不改写原始台词。
- 微软 TTS 继续只接收朗读文字，不使用 AI 语音指令。
