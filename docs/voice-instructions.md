# 配音语音指令

AI 配音提示词使用固定标签，模型只朗读 `合成文本`，其余标签都用于理解语境和控制表演：

```text
*指令：* [#用颤抖沙哑、带着崩溃与绝望的哭腔，夹杂着质问与心碎的语气说]
*引用上文：* [#是… 是你吗？怎么看着…好像没怎么变啊？]
*引用下文：* [#谢珩，你醒醒！别丢下我一个人。]
*合成文本：* 我逆转时空九十九次救你，你却次次死于同一支暗箭。谢珩，原来不是天要亡你……是你宁死也不肯为我活下去。
```

## 标签说明

- `指令`：必须说明语言、情绪、语气和表演方式，也可以包含参考音色、语速、停顿与时长要求。翻译服务返回的角色语气会自动写进这里。
- `引用上文`：当前台词之前、对理解人物关系和情绪有帮助的相邻台词，只供模型参考，不朗读。
- `引用下文`：当前台词之后、能帮助模型判断对话走向和表演落点的相邻台词，只供模型参考，不朗读。
- `合成文本`：唯一会被朗读的内容。这里保持标点、换行、省略号、停顿和重复，不要放角色名、说明或标签。

## 自动选择上下文

生成配音时，系统会按时间轴查找当前台词前后的相邻台词：

- 默认最多引用前 3 句、后 2 句。
- 相邻台词间隔超过 8 秒时停止继续引用，避免把无关场景拼进同一段提示词。
- 上下文优先使用译文；没有译文时使用原文。
- 用户已经填写的 `引用上文` 或 `引用下文` 会原样保留；只自动补齐缺失的一侧。
- 微软 TTS 仍然只接收 `合成文本`，不会使用 AI 语音提示词。

## 兼容格式

打开旧项目时，以下旧格式会自动迁移到新标签，不会改写实际台词：

```text
[#用轻松的语气说]欢迎回来。
用轻松的语气说：「欢迎回来。」
【配音要求】：放慢语速
【角色语气】：温柔期待
【配音台词】：「欢迎回来。」
```
