# UI 验收记录 · 2026-09-23

本次沿用暖灰底色、陶土色重点按钮和 Carbon 图标，优先修复页面无法加载、空间浪费、控件错位及交互入口缺失的问题。

## 问题与修复

| 程度 | 问题 | 修复 |
| --- | --- | --- |
| 阻断 | 设置页重命名、音频左右键事件和任务列表样式存在语法错误，页面无法编译 | 将模板中的多条语句移入脚本函数，补齐样式括号；单独整理已有设置重构 |
| 高 | 项目栏仅 216px 且内边距过大，项目名过早截断 | 桌面项目栏改为 272–320px，较窄桌面为 256px；横向内边距降至 8px；名称支持两行及悬停完整显示 |
| 高 | 侧栏收起后无法在当前项目内切换配音与预览 | 窄窗口增加两个标准导航按钮，保留明确的当前页面状态 |
| 高 | 生成弹窗缺少可见关闭入口，打开后焦点留在背景页面 | 配音和翻译弹窗补齐标题、关闭按钮和无障碍名称；打开聚焦输入框，关闭返回触发按钮 |
| 中 | 首页、配音与设置页存在较大的固定留白及内容宽度限制 | 统一页面边距；压缩设置分类栏；配音表格减小行距、列距和操作区占用 |
| 中 | 导入页只有一个名称字段却仍使用双列表单 | 名称输入框铺满整行，导入区适当加宽 |
| 中 | 音色行、参数、参考音频在窄窗口中容易挤压 | 音色行与参数允许换行；长名称与语气省略并保留完整提示；音频控件按可用宽度调整时长显示 |
| 中 | 预览在低高度或窄窗口中可能挤没视频与音轨 | 保留视频最小可用高度，允许预览区域滚动，缩短音轨说明列 |
| 中 | 按钮、图标和辅助文字大小不一致 | 统一标准按钮与输入控件尺寸；语气选项使用 Nuxt UI 按钮；翻译图标统一为 Carbon translate；辅助文字至少 12px |
| 中 | 任务操作按钮无边框且点击面积过小，浮层位置不符合右下角预期 | 浮层放在右下角；操作统一为 28px 带边框图标按钮，触摸设备使用至少 44px 点击区 |
| 中 | 文字颜色混用，部分辅助文字偏淡 | 统一正文、辅助、状态语义色；增强辅助文字对比度；移除无效文字颜色类名 |
| 中 | 已启用渠道显示的并发数可能与队列实际设置不同 | 列表与编辑表单读取当前生效并发数，避免误导用户或保存时意外改小 |
| 低 | 密钥输入框的尾部按钮占用输入内容空间，部分开关缺少名称 | 为输入内容预留尾部空间，补齐图标按钮、开关、滑块和重命名输入的标签 |

## 验证

- Electron 实测：项目列表、导入、配音表格、配音弹窗、AI 音色弹层、预览、任务面板，以及渠道、音色、通用设置页面。
- 响应式实测：正常桌面窗口、1024 × 768、390 × 844；已退出设备模拟并关闭开发者工具。
- 键盘实测：配音弹窗打开后聚焦输入框，关闭后返回对应句子的配音按钮。
- 浅色主题的辅助文字和主要语义文字色，在三种主要页面底色上的计算对比度均超过 4.5:1。此结果不等同于完整的无障碍认证。
- 类型检查、生产构建、113 项现有测试通过；设置整理的独立暂存快照也通过类型检查。

本轮验证没有提交真实翻译或配音请求，没有启动导出、下载更新或安装。暗色主题补齐了基础颜色变量，未进行完整逐页视觉验收。
