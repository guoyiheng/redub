## 验收边界

没有 Key 的 AI 调用应明确提示缺少配置，不能伪造识别、翻译或配音结果。
文本从台词步骤开始，音频跳过视频抽轨，视频执行全部步骤。
只替换启用的片段；未替换的人声与全长背景继续保留。
模型分离与参考音色合成存在质量差异，最终质量通过逐片段试听与导出预览确认。
发布签名、更新托管地址和真实付费 API 验证所需资料若未提供，应如实记录未验收项。
